## Features

* **Real-time Inventory Management:** Track stock levels in real-time, preventing stockouts and overstocking.
* **Cashier Activity Monitoring:** Monitor cashier transactions and activities for enhanced security and accountability.
* **Comprehensive Reporting:** Generate detailed reports on sales, inventory, and financial performance.
* **Financial Target Tracking:** Set financial targets and visualize progress with intuitive dashboards.
* **Goods Received Note (GRN) Implementation:** Streamline the process of receiving and recording new inventory.
* **User-Friendly Interface:** Intuitive Swing-based graphical user interface for ease of use.
* **Customizable:** Adaptable to the specific needs of various medium-sized businesses and shops.
* **Data Visualization:** Utilize JFreeChart for visually appealing and informative dashboards.

## Technology Stack

* **Java:** The primary programming language.
